# Algorithm Visualizer

A full-stack web application for visualizing complex algorithms in 3D using React and FastAPI.

## Project Structure

This repository is divided into two main parts:
- **[frontend](./frontend)**: A React application built with TypeScript, Vite, Tailwind CSS, and `react-force-graph-3d` for immersive 3D visualizations.
- **[backend](./backend)**: A fast, modern Python backend built with FastAPI to handle algorithmic computations and serve data to the frontend.

## Getting Started

To get a local copy up and running, please refer to the individual README files in the respective directories:

### 1. Backend Setup
Navigate to the `backend` directory and follow the instructions in the [Backend README](./backend/README.md) to set up the Python environment and run the FastAPI server.

### 2. Frontend Setup
Navigate to the `frontend` directory and follow the instructions in the [Frontend README](./frontend/README.md) to install dependencies and start the React development server.

## Technologies Used
- **Frontend**: React, TypeScript, Vite, Zustand, Tailwind CSS, Three.js, React Force Graph 3D, Recharts.
- **Backend**: Python 3.13+, FastAPI.
